# Zeliha's TicketLab

## Project Overview

TicketLab is an interactive IT Support practice application based on everyday Level 1 Service Desk scenarios.

Users can practise troubleshooting, customer communication, incident handling and ticket documentation.

## Project Purpose

I started this project to improve my IT Support skills while practising HTML, CSS and JavaScript.

My aim is to create a practical learning tool for myself and others preparing for First-Line IT Support, Helpdesk and Service Desk roles.

## Project Scope

The aim is to create 300 Level 1 IT Support scenarios across 10 categories, with 30 scenarios in each category.

Ticket scenarios and customer responses will be stored in separate JSON files.

Each scenario will contain around 20 predefined customer responses covering the issue, error messages, previous attempts and troubleshooting results.

Users will not see these responses in advance. They will need to ask relevant questions and suggest troubleshooting steps to investigate and resolve the issue.

The simulated customer will respond to matching questions and report whether the suggested steps worked. If no matching response is available, the customer will ask the user to try another question.

## How to Use

1. Select an IT Support ticket.
2. Read the customer details and problem description.
3. Start the call.
4. Ask questions to investigate the issue.
5. Suggest troubleshooting steps.
6. Identify the possible root cause.
7. End the call.
8. Document your findings in the internal note.

## How to Run Locally

1. Download or clone the repository.
2. Open the project folder.
3. Open lab.html in a web browser.
